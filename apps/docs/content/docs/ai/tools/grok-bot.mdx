[Grok Bot](https://cursor.com/docs/grok-bot) is Cursor's app for persistent AI agents. Its Marketplace includes the Prisma plugin, with one hosted MCP connection and two skills for Prisma ORM 8 and Prisma Composer.

## Add the Prisma plugin

1. Select **Plugins** in the sidebar, then search the Marketplace for **Prisma**.
2. Open the Prisma plugin and select **Add**.
3. Complete authorization in your browser and choose the Prisma workspace when prompted.
4. Check **Installed** to confirm Prisma was added.

The plugin connects to `https://mcp.prisma.io/mcp`. You do not need a local MCP server. If a team admin has disabled the plugin, ask them to enable it in your Cursor team's Marketplace. See [Cursor's plugin connection guide](https://cursor.com/help/grok-bot/connect-plugins) for more about authorization and team controls.

## Work with Prisma

Use the [MCP guide's sample prompts](/ai/tools/mcp-server#sample-prompts) to work with Prisma Postgres, existing Compute deployments, and Object Storage. The [MCP tools reference](/ai/mcp-tools) lists supported operations and their limits.

For code work, the plugin includes `prisma-orm` and `prisma-composer` skills. Follow the [Prisma 8 skills guide](/ai/tools/skills#available-skills-for-prisma-8) and [Composer skills guide](/ai/tools/skills#available-skills-for-prisma-composer) for project skill setup.

If you use the Cursor editor, see its separate [Prisma plugin setup](/ai/tools/cursor).
